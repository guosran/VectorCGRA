Architecture Summary (Critical Details)

CGRA: 4×4 tiles, compiled_ii=15 (15 control steps per iteration), 15 active cores (0-14), core 15 unused. tile_id = col + row*4. Row 0 = bottom, Row 3 = top.

TileRTL (tile/TileRTL.py): Each tile contains:
- CtrlMemDynamicRTL: Stores 15 control words, cycles through them. times counter tracks completed steps. Advances when send_ctrl.rdy & send_ctrl.val.
- Routing crossbar (CrossbarRTL, 8 inputs → 8 outputs): inputs 0-3 = tile inports (N,S,W,E), inputs 4-7 = register banks. Outputs 0-3 = tile outports (N,S,W,E), outputs 4-7 = register cluster lanes → FU.
- FU crossbar (CrossbarRTL): routes FU outputs to tile outports and register cluster.
- FlexibleFuRTL: The functional unit.
- RegisterClusterRTL: 4 banks of 8 registers each.
- ChannelRTL (latency=1): Each tile inport has a 2-entry buffered queue providing 1-cycle latency.
- Three done-latching signals: element_done, routing_crossbar_done, fu_crossbar_done. The ctrl advances ONLY when all three are done: ctrl_mem.send_ctrl.rdy = (element.recv_opt.rdy | element_done) & (routing_crossbar.recv_opt.rdy | routing_crossbar_done) & (fu_crossbar.recv_opt.rdy | fu_crossbar_done).

CrossbarRTL (noc/CrossbarRTL.py, 281 lines): ALL-OR-NOTHING delivery. recv_opt.rdy requires:
1. all_send_accepted: All required output sends accepted by downstream.
2. reduce_and(recv_valid_or_prologue_allowing_vector): ALL required input data present (or bypassed by prologue).

For each output i, in_dir[i] (from crossbar_outport[i]) specifies which input feeds it. If in_dir[i] > 0, that input must have val=1 (data present), otherwise the crossbar blocks.

Prologue mechanism: For the first iteration, some operations have no upstream data yet (e.g., PHI_START). The prologue counter per (step, inport) lets the crossbar skip waiting for that input during the first N iterations. Configured via CMD_CONFIG_PROLOGUE_ROUTING_CROSSBAR, CMD_CONFIG_PROLOGUE_FU, CMD_CONFIG_PROLOGUE_FU_CROSSBAR packets.

Select encoding: 0=nothing, 1=input[0](N), 2=input[1](S), 3=input[2](W), 4=input[3](E), 5=input[4](reg0), ...

Port directions: PORT_NORTH=0, PORT_SOUTH=1, PORT_WEST=2, PORT_EAST=3. In CgraRTL mesh: tile[i].send_data[NORTH] → tile[i+width].recv_data[SOUTH].
